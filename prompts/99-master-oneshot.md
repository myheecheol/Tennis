# 마스터 프롬프트 (원샷 버전)

**단계별로 돌릴 시간이 없을 때 한 번에 기획서를 뽑는 프롬프트입니다.**

> ⚠️ 솔직히 말하면 **품질은 STEP 1~7 체인이 훨씬 낫습니다.**
> 원샷은 카드 품질이 확실히 떨어지고, 전술 오류도 더 많이 섞입니다.
> 다음 두 경우에만 쓰세요.
> - 일단 전체 그림을 빠르게 보고 방향을 잡고 싶을 때
> - 체인을 돌리기 전에 "무엇이 부족한지" 미리 확인하고 싶을 때

---

```text
[STEP 0 공통 컨텍스트 블록을 여기 붙여넣기]
[reference/doubles-domain-pack.md 전문]
[reference/court-coordinates.md 전문]
[reference/card-exemplars.md 전문]
[reference/platform-recommendation.md 전문]

---

당신은 다섯 사람의 능력을 동시에 가진 프로덕트 리드입니다.
① 테니스 복식 코치(지도 15년) ② 교육과정 설계자 ③ 학습형 모바일 게임 디자이너
④ 인터랙션 디자이너 ⑤ 1인 앱 스튜디오 운영자

위 자료를 바탕으로, **테니스 복식 상황 학습 게임의 제품 기획서**를 작성하세요.
개발자가 이 문서만 보고 착수할 수 있는 수준이어야 합니다.

## 진행 방식 — 반드시 이 순서로, 각 단계를 눈에 보이게 쓰세요

**[1단계] 커리큘럼**
5챕터 구조 + 전체 카드 목록(100~130장)을 표로.
컬럼: id / 챕터 / 제목 / 내 역할 / 질문 유형(move·target·both·readNext) / 난이도 / 선행 / 원칙(P-01~05)

**[2단계] 카드 완성본 8장**
전체 목록 중 **각 챕터를 대표하는 8장**을 골라, `card-exemplars.md` 형식 그대로
(사람이 읽는 본문 + JSON) 두 벌로 작성. 스키마는 `court-coordinates.md`를 따릅니다.
오답은 반드시 2개 — `차선` 1개, `실수` 1개.

**[3단계] 코트 시각화 명세**
좌표 변환 / 마커 규칙(**"나"를 튀게 만드는 장치 2가지 포함**) / 화면 상태 5가지 /
정답 애니메이션 타임라인(ms 단위 표) / 탭 판정 / 접근성 / 디자인 토큰(다크·라이트).

**[4단계] 게임 설계**
코어 루프 / 채점(정답·차선·실수) / 모드 4가지(학습·복습·압박·랠리) /
성장 시스템 / 난이도 적응(목표 정답률 숫자) / 푸시 문구 5개 / 온보딩 첫 60초.

**[5단계] 플랫폼·수익화**
첨부한 `platform-recommendation.md`를 **초안으로 보고 검토**하세요.
동의만 하지 말고, 틀렸다고 보는 부분은 반박하세요.
플랫폼 대안 4가지(웹→Flutter / Flutter만 / Expo / 웹만)를 5축으로 비교한 표를 만들고
**하나를 고르세요.** 이어서 기술 스택 / 가격 / 무료·유료 경계 / Phase별 로드맵(주 단위,
통과 기준 숫자 포함) / 12개월 비용(원화) / 리스크 5개.

**[6단계] 기획서 조립**
1~5단계를 하나의 기획서로 통합. 목차:
한 장 요약 / 문제 정의 / 사용자·시나리오 / 제품 정의 / 콘텐츠 설계 / 시각 설계 /
기술 / 수익화 / 로드맵 / 지표(북극성 1 + 보조 5, 목표값 포함) / 리스크 / 결정 로그 /
부록(미해결 질문, 용어집).

**[7단계] 자기 검수**
네 사람의 눈으로 당신의 기획서를 비판하세요. 각 3가지씩, 칭찬 없이 문제만.
① 코치(전술 오류) ② 게임 디렉터(3일 차 이탈 지점) ③ 1인 개발자(구현 불가·일정)
④ 사용자(안 와닿는 부분·돈 낼 의향).
그다음 심각도 순 문제 표를 만들고, `치명` 항목은 **해당 절을 다시 써서** 첨부하세요.

## 전역 규칙
- STEP 0의 "절대 규칙" 7가지를 전부 지킨다
- 도메인 팩의 "AI가 자주 만드는 오답" 6가지를 반복하지 않는다
- 지어낸 통계 금지. 모르면 `[확인 필요]`로 표시
- 형용사가 아니라 숫자로 설명한다
- 분량이 길어지면 **표를 쓰고 산문을 줄인다**

## 출력이 길어 잘릴 경우
1~4단계를 먼저 출력하고 `[계속]`이라고 표시한 뒤 멈추세요.
제가 "계속"이라고 하면 5~7단계를 이어서 쓰면 됩니다.
```

## 원샷 결과를 받은 뒤 반드시 던질 후속 프롬프트

```text
지금 만든 기획서에서 가장 약한 부분은 [2단계 카드]입니다.
원샷으로 만든 카드는 오답이 허수아비이거나, 해설이 감각적 표현에 기대는 경향이 있습니다.

당신이 만든 8장을 다시 읽고, 아래 기준으로 **가장 약한 3장을 골라 다시 쓰세요.**
- 세 보기가 모두 코트에서 실제로 벌어지는 선택인가
- 해설이 물리적 이유(네트 높이 / 거리 / 몸의 방향)로 설명되는가
- 단서(cue)가 눈으로 관찰 가능한가
- 한 줄 요약이 코트 위에서 떠오를 문장인가

다시 쓴 뒤, 무엇을 왜 바꿨는지 각각 한 문장으로 덧붙이세요.
```
