# STEP 1 — 커리큘럼 설계 프롬프트

**목적**: 상황 카드를 마구잡이로 만들기 전에 **배우는 순서**를 먼저 정합니다.
**입력**: STEP 0 블록 + `reference/doubles-domain-pack.md`
**출력**: 챕터 구조 / 카드 목록 / 선행관계 / 난이도 곡선

---

```text
[STEP 0 공통 컨텍스트 블록을 여기 붙여넣기]
[reference/doubles-domain-pack.md 전문을 여기 붙여넣기]

---

당신은 두 사람입니다. 둘 다의 관점으로 답하세요.

(1) 테니스 복식 전문 코치 — 동호인 지도 15년. 초보가 어디서 무너지는지 안다
(2) 교육과정 설계자(instructional designer) — 학습 순서와 인지 부하를 설계한다

## 할 일
위 도메인 팩의 30개 상황을 재검토해서, **초보자가 실제로 배울 수 있는 순서**로
커리큘럼을 재설계하세요. 도메인 팩의 목록은 초안일 뿐이니 자유롭게 고치고, 빼고, 더하세요.

## 설계 제약
- 총 **5개 챕터**, 챕터당 **20~26장**, 전체 **100~130장**
- 1챕터는 반드시 **무료 체험**으로 성립해야 한다 → 그것만 해도 코트에서 뭔가 달라지는 내용
- 한 장은 **60~90초**에 푼다 (문제 읽기 + 판단 + 해설 읽기)
- 난이도 1~5. 챕터 안에서 1→4로 올라가되, **챕터 시작은 항상 난이도를 한 칸 낮춘다**
- 인지 부하: 한 챕터에서 새로 도입하는 **개념은 최대 4개**. 나머지는 기존 개념의 재적용

## 출력 형식

### 1. 학습 여정 한 문단
"1챕터를 끝낸 사람은 코트에서 무엇이 달라지는가"를 챕터별로 한 문장씩. 총 5문장.

### 2. 챕터 구조 표

| 챕터 | 제목 | 한 줄 목표 | 카드 수 | 새 개념 | 난이도 범위 |
|---|---|---|---|---|---|

### 3. 전체 카드 목록 표 (100~130행 전부)

| id | 챕터 | 카드 제목 | 내 역할 | 질문 유형 | 난이도 | 선행 카드 | 핵심 원칙 |
|---|---|---|---|---|---|---|---|

- `id`: `C1-01` 형식
- `내 역할`: 서버 / 넷맨 / 리시버 / 리시버 파트너 / 랠리
- `질문 유형`: move(어디로 움직일까) / target(어디로 칠까) / both / readNext(다음에 무슨 일이 일어날까)
- `핵심 원칙`: P-01 ~ P-05 중 하나

### 4. 질문 유형 분포 점검
전체에서 move / target / both / readNext 비율을 세어 표로 제시하고,
한쪽으로 치우쳤다면 어떻게 조정했는지 한 문단.
(목표 비율: move 40% / target 35% / both 15% / readNext 10%)

### 5. 무너지는 지점 예측
"초보자가 이 커리큘럼에서 이탈할 가능성이 가장 높은 카드 3장"을 지목하고,
각각 왜 어려운지 + 그 앞에 어떤 디딤돌 카드를 넣었는지 설명.

### 6. 자기 검증
아래를 표로 자문자답하고, ❌가 하나라도 있으면 **답변을 고쳐서 다시 제출**하세요.
- [ ] 모든 카드가 P-01~P-05 중 하나에 연결되는가
- [ ] 선행 카드가 항상 자기보다 앞 번호인가 (순환 참조 없음)
- [ ] 1챕터만으로 "코트에서 달라지는 것"이 실제로 있는가
- [ ] 같은 판단을 묻는 중복 카드가 없는가
- [ ] 한 챕터에 새 개념이 5개 이상 들어간 곳이 없는가

## 금지
- 스트로크/서브 기술, 체력, 멘탈 카드를 넣지 말 것
- "기본기를 익힌다" 같은 측정 불가능한 목표 금지
- 도메인 팩의 "AI가 자주 만드는 오답" 6가지를 그대로 반복하지 말 것
```

## 이 프롬프트가 잘 작동하는 이유

- **두 개의 역할**을 준 것: 코치만 주면 정확하지만 학습 순서가 엉망이고, 교육 설계자만 주면 순서는 좋은데 전술이 틀립니다
- **초안을 고치라고 시킨 것**: 백지에서 만들라고 하면 일반론이 나옵니다. 고치라고 하면 판단이 나옵니다
- **자기 검증 체크리스트**: 순환 참조 같은 실수를 AI가 스스로 잡습니다
- **이탈 지점 예측**: 이걸 시키면 AI가 난이도를 진지하게 다시 봅니다
