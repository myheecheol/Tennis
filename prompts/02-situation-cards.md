# STEP 2 — 상황 카드 생성 프롬프트 (핵심)

**목적**: 커리큘럼의 카드 목록을 **바로 개발 가능한 데이터**로 만듭니다.
**입력**: STEP 0 + 도메인 팩 + 좌표계 + 카드 예시 + STEP 1의 카드 목록
**출력**: 카드 JSON 배열 + 사람이 읽는 카드 본문

> ⚠️ **한 번에 100장을 요구하지 마세요.** 품질이 반드시 무너집니다.
> **한 번에 8장씩**, 챕터 단위로 끊어서 돌리세요.

당신은 테니스 복식 코치이자 퀴즈 문항 설계자입니다.
위 카드 목록 중 **{C1-01 ~ C1-08}** 8장을 완성본으로 작성하세요.
(작업할 범위만 바꿔가며 이 프롬프트를 반복 사용합니다)

## 각 카드는 두 벌로 출력한다

### (가) 사람이 읽는 본문 — `card-exemplars.md`의 "사람이 보는 화면" 형식 그대로
### (나) 데이터 — `court-coordinates.md`의 JSON 스키마 그대로

## 작성 규칙

**단서(cue)**
- **눈으로 보이는 것만** 쓴다. 관찰 가능해야 한다
- ⭕ "리시버가 두 걸음 끌려나갔고 백스윙이 늦다" / "상대 넷맨이 네트에 바짝 붙어 있다"
- ❌ "상대가 약하다" / "분위기가 우리 쪽이다" / "상대가 긴장했다"
- 단서는 **1~2개만**. 세 개를 넘으면 초보자가 무엇을 보라는 건지 모른다

**정답(answer)**
- `short`는 **동사로 끝나는 한 문장**. "가운데로 두 걸음, 가로챈다"
- `why`는 **2~3문장**. 첫 문장은 "왜 상대가 그렇게 칠 수밖에 없는가",
  둘째 문장은 "그래서 내가 어디 있어야 하는가"
- 물리적/기하학적 이유를 댄다. "네트가 가장 낮다", "몸이 열리기 전에 쳐야 한다",
  "코트가 가장 길다" — 감각적 표현("느낌이 좋다") 금지

**오답(distractors) — 정확히 2개**
- 1개는 `"차선"`: 나쁘지 않지만 기회를 버리는 선택. **초보자가 실제로 가장 많이 하는 선택**
- 1개는 `"실수"`: 본능적으로 끌리지만 틀린 선택. **왜 끌리는지를 먼저 인정한 뒤 반박한다**
  - 형식: "~하려는 마음은 자연스럽다. 그런데 ~"
- 세 보기 모두 코트에서 실제로 벌어지는 일이어야 한다

**한 줄 요약(coachLine)**
- **코트 위에서 떠오를 문장.** 15자~30자
- 대구/대조 구조를 쓰면 잘 남는다
  - "직선을 지키는 사람이 아니라, 가운데를 먹는 사람"
  - "가운데는 상대 넷맨이 없을 때 정답이다"
- 격언조 남발 금지. 8장 중 대구 구조는 3장 이하

**좌표(xy)**
- 반드시 존 코드 범위 안. 존 경계에 딱 붙이지 말고 **존 중앙 부근**에 둔다
- 네 사람이 모두 겹치지 않게 (서로 최소 0.12 이상 떨어뜨린다)
- 마커가 코트 밖으로 나가는 상황(끌려나간 상황)은 `x`를 0 미만 / 1 초과로 써도 된다

## 다양성 강제
8장을 다 쓴 뒤 아래를 점검하고, 치우쳤으면 **고쳐서 다시 제출**하세요.
- 정답 존이 8장 중 3장 이상 같으면 안 된다
- 내 시작 위치가 8장 모두 같은 쪽(듀스/애드)이면 안 된다
- `coachLine` 8개가 서로 같은 문장 구조면 안 된다

## 반복 실행 요령

1. `C1-01 ~ C1-08` → 검토 → 수정 지시 → 확정
2. 확정된 8장 중 **가장 잘 나온 2장을 예시에 추가**하고 다음 배치 실행
   → 배치를 거듭할수록 품질이 올라갑니다 (예시가 누적되므로)
3. 챕터가 끝나면 **챕터 통합 검토** 프롬프트를 한 번 돌립니다:

```text
지금까지 만든 C1 챕터 24장을 한꺼번에 검토하세요.
1. 같은 판단을 묻는 중복 카드가 있는가 — 있으면 어느 것을 버릴지 결정
2. 난이도가 1→4로 매끄럽게 올라가는가 — 튀는 카드를 지목하고 재배치
3. 정답 존 분포를 세어 표로 제시 — 한쪽에 몰려 있으면 카드를 고쳐라
4. 24장을 다 푼 사람이 코트에서 실제로 할 수 있게 되는 것을 3가지로 정리
```

## 흔한 실패와 처방

| 증상 | 원인 | 처방 |
|---|---|---|
| 카드가 다 비슷비슷하다 | 배치가 너무 큼 | 8장 이하로 끊는다 |
| 오답이 허수아비다 | "차선/실수" 구분을 안 시킴 | severity 규칙을 다시 강조 |
| 전술이 틀렸다 | 도메인 팩을 안 붙임 | 매번 붙인다. 요약본 말고 전문 |
| 해설이 뜬구름 | "물리적 이유" 요구를 안 함 | "네트 높이/거리/몸의 방향으로 설명하라" 추가 |
| 좌표가 엉망 | 좌표계를 안 붙임 | court-coordinates.md 전문 첨부 |
