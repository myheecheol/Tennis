# 플랫폼·수익화 판단 (질문에 대한 답)

> "웹앱보다는 iOS/안드로이드 앱으로 만들어야겠지? 수익 창출까지 하면 좋으니까. 아닐까?"
> → **결론부터: 최종 형태는 모바일 앱이 맞습니다. 하지만 "처음부터" 앱으로 시작하면 안 됩니다.**

---

## 1. 결론 요약

| | 추천 |
|---|---|
| **최종 형태** | iOS + Android 네이티브 앱 (스토어 출시) |
| **시작 형태** | 웹 프로토타입 (1~2개월, 카드 30장으로 콘텐츠 검증) |
| **기술 스택** | **Flutter** (1순위) 또는 **React Native + Expo** (2순위) |
| **수익 모델** | 구독형 프리미엄 (무료 1챕터 + 유료 전체) |
| **가격** | 월 4,900원 / 연 29,000원 (연간 유도) |
| **광고** | 초기 도입 안 함 |

---

## 2. 왜 모바일 앱이 맞는가

**① 푸시 알림 = 학습 앱의 생명줄**
학습 앱의 수익은 결제가 아니라 **리텐션**에서 나옵니다. 돌아오게 만드는 유일한 도구가 푸시입니다.
웹은 iOS에서 푸시가 사실상 무력합니다(홈 화면 추가를 해야 겨우 동작). 이건 결정적인 차이입니다.

**② 결제 전환율**
앱스토어 인앱결제는 지문 한 번으로 끝납니다. 웹 결제는 카드번호 입력에서 대부분 이탈합니다.
수수료 15~30%를 내고도 앱이 유리한 이유입니다.
(참고: 매출 100만 달러 미만 개발사는 애플·구글 모두 **수수료 15%** 적용)

**③ 사용 맥락이 코트 옆이다**
동호회 대기 시간, 레슨 직전, 이동 중 — 전부 폰입니다. 데스크톱에서 복식 전술을 공부하지 않습니다.

**④ 오프라인**
실내 코트는 신호가 잘 안 잡힙니다. 앱은 콘텐츠를 내려받아 둘 수 있습니다.

---

## 3. 그런데 왜 "처음부터" 앱은 안 되는가

이 프로젝트의 진짜 리스크는 **기술이 아니라 콘텐츠**입니다.
"상황 카드가 실제로 재미있고, 실제로 실력이 늘까?" — 이건 만들어봐야 압니다.

앱으로 먼저 가면 이 검증에 비용이 붙습니다.

| 항목 | 웹 | 앱 |
|---|---|---|
| 카드 하나 고쳐서 반영 | 즉시 | 심사 1~3일 |
| 테스터에게 보여주기 | 링크 하나 | TestFlight 초대 |
| 첫 배포까지 | 당일 | 개발자 계정 + 심사 (애플 $99/년) |
| 사용자 반응 측정 | 바로 | 설치 장벽 통과 후 |

**동호회 단톡방에 링크 하나 던져서 30명 반응을 보는 것** — 이게 초기에 가장 값진 데이터입니다.
그리고 그 링크는 앱스토어 링크면 안 됩니다.

## 4. 권장 3단계 로드맵

### Phase 1 — 검증 (0~2개월) · 웹
- 상황 카드 **30장**, 코트 렌더러, 정답/해설, 정답률 로깅
- 회원가입 없음. 결제 없음. 링크만 공유
- **성공 기준**: 시작한 사람의 60%가 30장을 끝까지 / "다음 챕터 언제 나와요?" 소리가 나오는가
- 실패하면 → **여기서 멈추고 콘텐츠를 고칩니다.** 앱을 만들지 않습니다.

### Phase 2 — 제품화 (2~5개월) · Flutter / Expo
- 카드 **120장**(5챕터), 오답 노트, 스트릭, 레벨, 푸시
- iOS + Android 동시 출시, 웹은 랜딩+체험판으로 유지
- 무료: 1챕터(24장) / 유료: 전체 + 오답 복습 + 랠리 시뮬레이션
- **성공 기준**: D7 리텐션 25% / 무료→유료 전환 3~5%

### Phase 3 — 확장 (5개월~)
- 랠리 시뮬레이션(한 포인트 5수 연속), 주간 리그, 동호회 랭킹
- 코치용 B2B (레슨 보조 교재 라이선스)
- 콘텐츠 확장: 단식 / 서브·리턴 심화 / 포메이션 심화

## 5. Flutter vs React Native(Expo)

| 기준 | Flutter | Expo (RN) |
|---|---|---|
| 코트 그리기·애니메이션 | **강함** (`CustomPainter`로 직접 그림, 60fps 안정) | 가능하지만 `react-native-svg`/Skia 얹어야 함 |
| 웹까지 한 코드베이스 | 됨 (다소 무거움) | **강함** (웹 빌드가 자연스러움) |
| 개발 속도 | 보통 | **빠름** (OTA 업데이트로 심사 없이 콘텐츠 반영) |
| 이 프로젝트 적합도 | 그래픽 품질을 최우선 → **1순위** | Phase 1 웹을 그대로 재사용 → **2순위** |

**Flutter를 1순위로 두는 이유**: 이 앱의 화면은 사실상 **전부 코트 그림**입니다.
마커, 화살표, 존 하이라이트, 이동 애니메이션이 제품 그 자체입니다.
직접 그리는 캔버스 API가 일급인 프레임워크가 유리합니다.

**Expo를 고를 조건**: Phase 1 웹을 React로 만들었고, 그 코드를 버리기 아깝다면 Expo가 맞습니다.

## 6. 수익 모델 상세

**구독형 프리미엄** (권장)

| 티어 | 가격 | 내용 |
|---|---|---|
| 무료 | 0원 | 1챕터(24장), 하루 5문제 |
| 프로 | 월 4,900원 / 연 29,000원 | 전체 카드, 오답 노트, 랠리 시뮬, 통계 |
| 코치 | 월 19,000원 | 회원 관리, 커리큘럼 배정, 진도 확인 |

**초기에 광고를 넣지 않는 이유**
문제를 푸는 중간에 들어오는 광고는 학습 몰입을 끊습니다.
학습 앱에서 광고 수익은 구독 대비 비교가 안 될 만큼 작고, 대신 리텐션을 갉아먹습니다.

**한국 시장 참고**
- 테니스 인구는 최근 몇 년 빠르게 늘었고, **동호회 중심**이라 입소문 경로가 명확합니다
- 레슨은 대부분 스트로크 위주 → **복식 전술은 배울 곳이 마땅치 않은 빈 칸**입니다
- 이 빈 칸이 이 제품의 존재 이유이자, 마케팅 메시지입니다

## 7. 리스크와 대응

| 리스크 | 대응 |
|---|---|
| 전술 내용이 틀렸다는 지적 | 출시 전 **실제 코치 2인 감수** 필수. 앱 안에 "이 카드 이상해요" 신고 버튼 |
| 콘텐츠 고갈 (다 풀면 할 게 없음) | 랠리 시뮬레이션 + 오답 기반 무한 복습 + 주간 신규 카드 |
| 정답이 하나뿐이라는 반발 | "정답/차선/실수" 3단계로 이미 대응. 해설에 "상황에 따라"를 명시 |
| 무료로 다 보고 이탈 | 무료 1챕터는 **기초**만. 유료는 실전 판단 |
| 애플 심사 반려 | 교육 앱 카테고리, 구독 조건 명시, 복원 버튼 필수 |
