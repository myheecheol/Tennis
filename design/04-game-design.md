# STEP 4 산출물 — 게임 설계

> `prompts/04-game-design.md` 를 실행한 결과입니다.
> 재료는 STEP 1 커리큘럼(120장)과 STEP 2 카드(1챕터 24장)입니다.

---

## 0. 이 제품의 특수성 — 설계가 여기서 갈린다

1. **정답이 하나가 아니다.** 정답 / 차선 / 실수 세 단계다. 점수 체계가 이걸 반영해야 한다.
2. **사용자는 주말에만 테니스를 친다.** 배운 걸 써먹는 주기가 일주일이다.
3. **목표는 앱 안의 점수가 아니라 코트 위의 행동 변화다.**

세 번째가 제일 중요합니다. 앱에서 만점을 받고 코트에서 얼어붙으면 이 제품은 실패입니다.

---

## 1. 코어 루프 — 30초

| 단계 | 화면 | 사용자가 느끼는 것 |
|---|---|---|
| 1 | 코트가 그려진다. 마커가 놓이고 공 경로가 지나간다 | **인식** — "아, 이 상황 안다" |
| 2 | 단서 한 줄이 뜬다 | **주목** — "저걸 보라는 거구나" |
| 3 | 질문 + 탭 가능한 존 세 곳 | **긴장** — "어디지" |
| 4 | 탭 | **결단** |
| 5 | 정답 존과 화살표가 그려진다 | **확인** 또는 **의외** |
| 6 | 해설 한 줄 | **납득** — "아 그래서" |
| 7 | 한 줄 요약 | **저장** — 이건 기억에 남는다 |
| 8 | `다음 →` | |

### "한 판 더"를 누르게 만드는 지점 — 6번과 7번 사이

납득이 온 직후입니다. 이때 사람은 **"다음 것도 알고 싶다"** 상태가 됩니다.
그래서 해설 끝에 `next`(다음 수)를 붙였습니다.
"포치에 성공하면 자리가 바뀐다 → C1-15" 를 읽은 사람은 다음 카드를 안 누를 수 없습니다.

**카드가 낱개가 아니라 랠리로 이어져 있다는 것** — 이게 이 게임의 엔진입니다.

---

## 2. 채점 — 차선을 어떻게 다룰 것인가

| 선택 | 점수 | 부수 경험치 | 오답 노트 |
|---|---|---|---|
| 정답 | 100 | +10 | 안 들어감 |
| 차선 | 60 | +4 | **들어감** (14일 뒤 재출제) |
| 실수 | 0 | 0 | 들어감 (1일 뒤 재출제) |

### 차선을 골랐을 때가 이 게임에서 가장 중요한 순간이다

초보자는 대개 차선을 고릅니다. 여기서 "틀렸습니다"가 뜨면 **의욕이 꺾이고, 실제로는 안 틀렸는데
틀렸다고 배웁니다.** 세 가지로 다르게 다룹니다.

| | 실수를 골랐을 때 | **차선을 골랐을 때** |
|---|---|---|
| 배지 | `✕ 실수` (붉은색) | `△ 차선` (호박색) — ✕ 를 절대 안 씁니다 |
| 첫 문장 | "이건 이래서 안 돼요" | **"나쁘지 않아요. 그런데 —"** |
| 화면 | 내 존은 빗금, 정답 존은 형광 | 내 존도 **옅은 형광**, 정답 존이 더 진하게 |
| 점수 | 0 | 60 — 0이 아니라는 게 핵심 |

차선의 해설은 **맞는 부분을 먼저 인정합니다** — "안전하지만, …" "방향은 맞아요. 다만 …".
한 문장 안에서 인정과 반박을 함께 합니다.

### 연속 정답 보너스 — 넣지 않는다

스트릭 보너스는 "틀리면 안 된다"는 압박을 만듭니다. 그러면 사람은 **확신 없는 카드를 피하게 됩니다.**
이 앱에서 가장 배울 게 많은 카드가 바로 그 카드입니다.
대신 **연속 학습일(요일 스트릭)** 만 셉니다. 정답률이 아니라 출석을 셉니다.

## 3. 게임 모드 넷

| # | 이름 | 규칙 | 시간 | 언제 | 해금 |
|---|---|---|---|---|---|
| a | **오늘의 코트** | 새 카드 5장 + 복습 3장 | 6분 | 매일 | 처음부터 |
| b | **오답 노트** | 틀리거나 차선을 고른 카드만 | 3분 | 알림이 뜰 때 | 오답 3장 쌓이면 |
| c | **10초 룰** | 카드당 10초. 시간 넘기면 무응답 처리 | 4분 | 실전 감각 점검 | 한 챕터 완료 |
| d | **한 포인트** | 5수 연속. 앞선 선택이 다음 상황을 바꾼다 | 5분 | 주 1~2회 | 두 챕터 완료 |

### (b) 오답 노트 — 간격 반복 알고리즘

| 선택 | 재출제 간격 |
|---|---|
| 실수 | 1일 → 3일 → 7일 → 21일 → 졸업 |
| 차선 | 3일 → 14일 → 졸업 |
| 재출제에서 또 틀림 | 간격을 **처음으로** 되돌린다 |
| 재출제에서 정답 | 다음 간격으로 |

**차선이 왜 더 긴 간격에서 시작하나** — 차선을 고른 사람은 원리를 이미 절반 압니다.
1일 뒤에 다시 보여주면 "아까 그거잖아"가 되어 기억이 아니라 인식으로 맞힙니다.

### (c) 10초 룰 — 왜 필요한가

코트에서는 생각할 시간이 없습니다. 앱에서 30초 고민해서 맞히는 건 실전에서 아무 소용이 없습니다.
**틀려도 부수 경험치를 깎지 않습니다.** 시간만 잃습니다. 벌 주는 모드가 아니라 감각 점검 모드입니다.

### (d) 한 포인트 — 분기 구조

한 판이 카드 5장이지만, **내가 고른 답에 따라 다음 카드가 달라집니다.**

```
C1-03  넷맨: 지금 나갈까?
 ├ 정답(A-CN 포치) ──→ C1-22  포치로 잡았다, 어디로 때리나
 │                      ├ 정답(E-CM) ──→ 🏆 포인트 획득
 │                      └ 실수(E-LB) ──→ C1-14  상대 반격, 파트너가 밀렸다
 ├ 차선(A-LN 제자리) ─→ C1-18  랠리가 이어진다, 크로스 딥이 왔다
 │                      └ …
 └ 실수(A-LM 물러섬) ─→ C1-19  로브가 머리 위로 넘어갔다
                        └ …
```

이 구조가 가능한 이유는 카드마다 **`next`(다음 수)** 가 이미 들어 있기 때문입니다.
분기표는 카드 데이터에서 대부분 자동으로 만들어집니다.

**포인트를 따면 이기는 게 아닙니다.** 5수 안에 몇 번 정답을 골랐는지가 기록됩니다.
실수로 시작해도 만회할 수 있어야, 실제 경기와 비슷합니다.

## 4. 성장 시스템 — 동호인 **부수**

레벨 1, 2, 3을 쓰지 않습니다. 한국 동호인 테니스에는 이미 모두가 아는 등급 체계가 있습니다.

```
신인부 → 5부 → 4부 → 3부 → 2부 → 1부
```

**숫자가 내려갈수록 올라간다**는 점이 오히려 좋습니다. 게임 등급이 아니라 진짜 등급처럼 읽힙니다.
동호회에서 "저 이번에 3부 됐어요"는 실제로 쓰는 말입니다.

| 등급 | 승급 조건 | 뜻 |
|---|---|---|
| 신인부 | 시작 | |
| 5부 | 1챕터 24장 완료 + 정답률 70% | 네 역할의 자리를 알아요 |
| 4부 | 2챕터 완료 + 오답 노트 졸업 10장 | 세 번째 공까지 봐요 |
| 3부 | 3챕터 완료 + 10초 룰 정답률 65% | 네트를 잡아요 |
| 2부 | 4챕터 완료 + 한 포인트 3승 | 밀려도 안 무너져요 |
| 1부 | 5챕터 완료 + 전 카드 오답 노트 졸업 | 상대를 읽어요 |

> ⚠️ **주의**: 앱의 부수는 실제 동호회 부수와 다릅니다.
> 앱 안에서 반드시 "**전술 부수**"로 표기하고, 오해가 없도록 첫 승급 때 한 번 설명합니다.
> 이 표기를 빠뜨리면 동호회에서 분쟁이 납니다.

### 역할별 숙련도 — **넣는다. 다만 보조로**

서버 / 넷맨 / 리시버 / 리시버 파트너 네 개의 막대를 따로 보여줍니다.

**왜 좋은가** — 초보자는 자기가 어느 역할에서 약한지 모릅니다.
"나는 넷맨일 때만 82%, 리시버 파트너일 때 41%"는 **다음에 무엇을 연습할지 알려주는 유일한 숫자**입니다.
그리고 이건 코트에서 바로 확인됩니다.

**왜 과할 수 있나** — 지표가 다섯 개(부수 + 역할 4)면 초보자는 무엇을 봐야 할지 모릅니다.
그래서 **부수만 크게, 역할 막대는 상세 화면에서만** 보여줍니다. 홈 화면 숫자는 하나입니다.

## 5. 난이도 적응

**목표 정답률 구간: 70~80%**

| 근거 | |
|---|---|
| 80% 위 | 너무 쉽다. 배우는 게 없고 지루해진다 |
| 70~80% | 다섯 장에 한 장쯤 틀린다. 틀린 게 기억에 남고, 맞힌 게 자신감이 된다 |
| 70% 아래 | 좌절 구간. 특히 초보 학습 앱에서 이탈이 급증하는 지점 |

### 무엇을 조절하나

| 정답률 | 조치 | 조절하지 않는 것 |
|---|---|---|
| 3장 연속 실수 | 다음 카드의 **선행 카드**를 끼워넣는다 (`prereq` 활용) | |
| 최근 10장 60% 미만 | 새 카드 비율 5→3장, 복습 3→5장 | |
| 최근 10장 85% 초과 | 난이도 +1 카드를 앞당긴다 | |
| — | | **보기 개수는 항상 3개.** 2개로 줄이면 찍어서 맞힌다 |
| — | | **제한 시간은 10초 룰 모드에서만.** 학습 모드에 시간 압박을 섞지 않는다 |

카드 데이터의 `prereq` 와 `difficulty` 가 이 로직의 전부입니다. 별도 데이터가 필요 없습니다.

## 6. 리텐션

### 푸시 알림 — 상황을 던진다

"학습하세요", "오늘의 문제가 도착했어요" 같은 문구는 쓰지 않습니다.
**알림 자체가 한 장의 카드여야 합니다.**

1. `상대가 로브를 올렸어요. 누가 쫓아갈까요?`
2. `파트너가 뒤로 밀렸어요. 나는 앞에 있어요. 어떻게 할까요?`
3. `세컨 서브가 짧게 왔어요. 상대 넷맨은 그대로 서 있어요.`
4. `넷맨이 가운데로 뛰었어요. 지금 열린 코스가 있어요.`
5. `가운데 뜬 공. 앞사람일까요, 뒷사람일까요?`

문장을 읽는 순간 이미 게임이 시작됩니다. 답을 확인하려면 열어야 합니다.

### 주간 리듬 — 주말에 치는 사람의 한 주

| 요일 | 성격 | 내용 |
|---|---|---|
| 월 | 쉼 | 알림 없음 |
| **화** | **복기** | "지난 주말, 이런 상황 있었죠?" — 주말에 나올 법한 카드 3장 |
| 수·목 | 학습 | 새 카드 진도 |
| **금** | **준비** | "이번 주 미션" 한 줄 배달 (아래 8번) |
| 토·일 | **침묵** | 경기하는 날. 알림을 보내지 않습니다 |

주말에 알림을 안 보내는 게 이 표에서 제일 중요합니다. 코트에 있는 사람에게 앱을 열라고 하면 안 됩니다.

### 스트릭 — 넣되, 완충 장치를 함께

- 세는 것은 **학습한 날 수**. 정답률이 아닙니다
- **주말 이틀은 자동으로 유지됩니다.** 테니스 치는 날 스트릭이 끊기면 말이 안 됩니다
- 평일에도 **월 2회 "쉬는 날"** 이 자동 적립됩니다
- 그래도 끊기면: 숫자를 0으로 되돌리지 않고 **"12일 → 다시 시작"** 으로 표시하고,
  최고 기록을 따로 남깁니다

스트릭의 부작용은 끊긴 날 이탈하는 것입니다. **끊긴 순간을 부드럽게 만드는 게 스트릭 설계의 전부입니다.**

## 7. 온보딩 첫 60초

| 초 | 화면 | 텍스트 |
|---|---|---|
| 0–3 | 코트가 그려지고 마커 넷이 놓인다 | — |
| 3–5 | `나` 마커에 발광 링이 한 번 크게 퍼진다 | — |
| 5–8 | 존 세 곳이 점선으로 드러난다 | **"코트를 눌러 답하세요"** (10자) |
| 8–35 | 사용자가 읽고 고민한다 | — |
| 35–45 | 정답 + 해설 + 한 줄 요약 | — |
| 45–55 | 한 줄 요약만 화면 가운데 크게 | — |
| 55–60 | `이런 상황이 120개 있어요` / `시작하기` | |

**튜토리얼 텍스트는 총 10자입니다.** 첫 문제 자체가 튜토리얼입니다.

### 첫 문제로 쓸 카드 — `C1-24` "뜬 가운데 공은 누가"

카드 목록의 마지막 장을 첫 문제로 쓰는 게 이상해 보이지만, 이유가 셋 있습니다.

1. **모든 동호인이 이 포인트를 잃어봤습니다.** 둘이 서로 쳐다보다가 가운데 공을 놓치는 장면.
   설명이 필요 없는 경험입니다.
2. **실수 보기가 "둘 다 서로를 보다가 아무도 안 가는 것"** 입니다.
   읽는 순간 웃습니다. 그리고 자기 얘기라고 느낍니다.
3. **정답이 한 줄 규칙입니다** — "뜬 가운데 공은 앞사람 것이다."
   이번 주말에 바로 써먹을 수 있습니다. **60초 만에 뭔가 얻어 간다**는 게 핵심입니다.

커리큘럼 순서를 어기는 게 아닙니다. 이건 맛보기이고, `시작하기`를 누르면 C1-01부터 시작합니다.

## 8. 코트로 나가는 다리 — **이번 주 미션**

앱 밖에서 실제로 쓰게 만드는 장치. 후보 여럿 중 하나만 고릅니다.

### 무엇인가

금요일 저녁, 이번 주에 배운 카드에서 **한 줄 규칙 하나**를 뽑아 보냅니다.

```
🎾 이번 주 미션
"넷맨은 직선을 지키는 사람이 아니라, 가운데를 먹는 사람이에요."

이번 주말, 넷맨일 때 딱 세 번만 가운데로 나가보세요.
```

### 왜 하나인가

셋을 주면 아무것도 안 합니다. 하나만 주면 그건 기억합니다.
코트에서 의식적으로 바꿀 수 있는 행동은 한 번에 하나입니다.

### 경기 후

일요일 저녁, **질문 하나만** 보냅니다. 30초 안에 끝나야 합니다.

```
가운데로 나가봤나요?
[ 세 번 이상 ]  [ 한두 번 ]  [ 못 했어요 ]  [ 안 쳤어요 ]
```

- `세 번 이상` → "다음 주는 포치 마무리를 해 봐요" + 관련 카드 3장 배지
- `한두 번` → "그것도 지난주보다 나은 거예요" + 같은 미션 한 주 더
- `못 했어요` → "몸이 안 따라 주는 건 정상이에요" + 같은 미션 + 쉬운 관련 카드 2장
- `안 쳤어요` → 아무 판단 없이 다음 주로

### 이게 왜 이 제품의 핵심인가

**앱에서 아무리 맞혀도 코트에서 안 움직이면 이 제품은 실패**라고 앞에서 썼습니다.
이 장치가 그 간극을 재는 유일한 측정기이자, 좁히는 유일한 도구입니다.
`세 번 이상` 응답률이 이 제품의 **북극성 지표**가 되어야 합니다.

---

## 9. 이 설계에서 가장 위험한 가정 셋

### ① "정답을 알면 코트에서 몸이 움직인다"

가장 크고 가장 검증되지 않았습니다. 지식과 행동 사이에는 반응 속도, 습관, 체력이 있습니다.

**무엇을 측정하면 알 수 있나** — 이번 주 미션의 `세 번 이상` 응답률.
4주 사용자와 신규 사용자를 비교합니다. **목표: 4주 사용자의 40% 이상.**
이 숫자가 15% 아래면 제품의 전제가 틀린 것이고, 콘텐츠가 아니라 **형식을 바꿔야 합니다.**

### ② "하루 6분을 매일 낸다"

학습 앱의 공통 착각입니다. 실제로는 주 2~3회가 현실적입니다.

**측정** — D7 리텐션과 주당 세션 수. **목표: D7 25%, 주 3회.**
주 3회가 안 나오면 "매일 6분" 대신 **"주 2회 15분"** 으로 루프를 재설계해야 합니다.
그 경우 `오늘의 코트`는 `이번 주 코트`가 되고 카드 수가 8장에서 20장으로 늘어납니다.

### ③ "정답이 하나라는 것에 반발하지 않는다"

복식 전술에는 "상황에 따라 다르다"가 정말로 많습니다. 구력이 있는 사용자일수록 이의를 제기합니다.

**측정** — 카드별 `이 카드 이상해요` 신고율. **한 카드가 2%를 넘으면 코치 재검토 대상.**
앱스토어 리뷰에서 전술 이의 제기가 차지하는 비율도 함께 봅니다.
정답/차선/실수 3단계로 이미 완화했지만, 충분한지는 실제로 내보내야 압니다.
